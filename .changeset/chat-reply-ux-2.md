A generated project's `sdlc` harness writes lighter replies and sets up models by itself. A reply that asks a question or stops at a gate starts with `**Waiting for you:**` and says what the person does. The steps of a playbook are in the agent tool's task list, and no reply holds a **Steps** section; the reply check blocks one. The agent writes no text while it works, asks a choice between ways through the agent tool's question picker where it has one, and names the checks that passed in one line. `/setup-sdlc` now sets the models only and edits no file of the project; send `/setup-sdlc project` for the steps of `SETUP.md`. A session with no models rule, such as a cloud session, writes the rule with the `balanced` budget and asks nothing. The agent now reaches first for a shell command or a script, such as `sed`, to change files, and makes a change that repeats in many places with one command in place of one edit for each place.
