A generated project's `sdlc` harness writes lighter replies, sets up models by itself, and drops rules that cost time for no check. A reply that asks a question or stops at a gate starts with `**Waiting for you:**` and says what the person does. The steps of a playbook are in the agent tool's task list, and no reply holds a **Steps** section; the reply check blocks one. The agent writes no text while it works and asks a choice between ways through the agent tool's question picker where it has one. `/setup-sdlc` now sets the models only and edits no file of the project; send `/setup-sdlc project` for the steps of `SETUP.md`. A session with no models rule, such as a cloud session, writes the rule with the `balanced` budget and asks nothing. The agent now reaches first for a shell command or a script, such as `sed`, to change files. In a build, the agent proposes the files, the order, and the tests in the plan, and the engineer corrects the plan. It no longer restates the request before it starts, starts a subagent for one command, reads a whole file before a search, or shows a whole draft again after one correction.
