A generated project starts the SDLC loop with a command named for the work: `/sdlc-intent`, `/sdlc-spec`, `/sdlc-plan`, `/sdlc-fix`, and `/sdlc-review`. They replace `/sdlc-mode`, whose name did not say what a person would get. The shared rules, playbooks, hooks, and scripts move from `.claude/skills/sdlc-mode/` to `.claude/skills/sdlc-loop/`, and the `Spec on intent merge` and `Control band` jobs send the new commands.
